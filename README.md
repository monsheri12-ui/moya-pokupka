# Моя покупка — монгольский магазин

Игра на понимание монгольской речи: запомните свою корзину, послушайте продавца, отметьте товары и введите сумму к оплате. Иногда звучит чужая покупка — её нужно распознать.

[Играть на GitHub Pages](https://monsheri12-ui.github.io/moya-pokupka/) · [Играть в Лисьей норе](https://foxsaywawa.tilda.ws/moya-pokupka)

В игре есть стартовое меню, загрузчик с повтором при ошибке, настройки размера корзины и скорости речи, сохранение покупки и разбор ошибок. Цены меняются между покупками.

Озвучка сгенерирована и передаёт произношение лишь приблизительно. Пожалуйста, уточняйте точное произношение у носителя монгольского языка.

## Запуск

Это статический сайт. Для локального запуска выполните `python3 -m http.server 8000` в корне репозитория и откройте `http://localhost:8000/`. Сервер синтеза и API-ключи не нужны: MP3 уже находятся в `assets/audio/`. Все пути относительные.

GitHub Pages публикуется из ветки `main`, папки `/ (root)`. Для Тильды используется файл `Tilda-embed.html` в блоке T123.

Файлы `app.js`, `engine.js` и `content.js` содержат интерфейс, игровые правила и банк корзин. Состояние сохраняется только в браузере игрока. Все денежные суммы учебные.
